# GitHub Sponsors Profile

## Short bio

I work in digital payments by day. In my spare time I build and maintain time-consuming WoW addons (Umbra Unit Frames, Hourstone, Soundstone) and web tools, tinker with local LLMs, and run a homelab.

## Introduction

Hi, I'm Martin — by day I work in digital payments and e-commerce, turning integration requirements into working solutions. Like most people, my day job pays the bills, not my hobby projects.

Outside of work, coding is both my outlet and my passion. I build World of Warcraft addons like **Umbra Unit Frames**, **Soundstone – Azeroth Audio**, and **Hourstone – Azeroth Hours** (plus its Windows companion app), all of which I use myself every time I play. I also build practical web tools like the **Computop Paygate Tester**, **Flux Card**, and **Flux Todo**, experiment with local LLMs, and run my own homelab.

All of these projects are built and maintained in my spare time, free and open source. The WoW addons in particular take up a lot of that time: every new patch or expansion can break things overnight, and keeping up with Blizzard's API changes, bug reports, and feature requests is an ongoing, unpaid effort squeezed into evenings and weekends.

This is not about needing money to get by — it's about time. Sponsoring me doesn't pay my bills, but it does let me justify spending another evening fixing a bug or shipping a feature instead of doing something else. Every bit of support, no matter how small, directly translates into more time spent making these projects better. Thank you for making that possible! 🙏
